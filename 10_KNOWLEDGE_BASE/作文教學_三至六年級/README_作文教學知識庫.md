# 國小三到六年級作文教學知識庫

## 定位

本知識庫供三至六年級國語文教案、作文課程、閱讀寫作整合、寫作學習單與作文鷹架設計按需載入。

本知識庫保存的是「作文教學方法、題材、結構、教學流程與學習單模板」，不是現行國語文課綱本身。正式教案仍須另外依 Canonical 課綱知識庫核對核心素養、學習表現與學習內容。

## 啟動條件

當三至六年級教案已確認涉及下列任一內容時，優先載入本知識庫：

- 作文、寫作、筆述
- 寫人、敘事、狀物、記景
- 說明文、議論文、應用文
- 書信、便條、日記、讀書報告
- 童話、童詩
- 審題、選材、大綱、段落、開頭、結尾
- 仿寫、範文分析、作文學習單
- 人物描寫、景物描寫、修辭與寫作詞彙

若只是一般國語文課程、閱讀理解或語詞教學，且沒有實際寫作任務，不因科目是國語文就自動載入。

## 核心教學循環

範文閱讀 → 文體辨識 → 審題 → 選材 → 寫作大綱 → 段落層次 → 口述／仿寫 → 完整寫作 → 賞析與修正

### 共通原則

1. 先判定題目的「範圍」與「重點」，再決定文體與結構。
2. 先蒐集內容，再安排段落；不要讓學生一看到題目就直接寫全文。
3. 每段維持一個主要思想或事件焦點。
4. 記敘文需兼顧實際內容與思想感情；感受可穿插在各段，不必全部堆到結尾。
5. 修辭與詞彙是表達工具，不以堆疊成語取代具體事件、觀察與感受。
6. 建議採「教師示範 → 分組討論 → 個人實作 → 賞析修正」，並逐步撤除鷹架。

# 三年級

## 三上主線

### 1. 記敘文：寫人

題材例：
- 我的老師
- 我的班長
- 我的媽媽
- 我的校長
- 我的音樂老師

教學重點：
- 從外表、個性、興趣、專長、工作或難忘事件蒐集內容。
- 用具體事件證明人物特質。
- 練習並列式或總分式結構。
- 真人真事之後加入自己的感受、感謝、希望或讚美。

建議四段：
1. 人物簡介＋外表
2. 個性＋事件例子＋我的感受
3. 興趣／專長＋事件例子＋我的感受
4. 感謝／希望／讚美

學習單：
- 人物：
- 我和他的關係：
- 外表／第一印象：
- 最明顯的個性：

- 他說了什麼／做了什麼：
- 興趣或專長：
- 我的感受：
- 我想感謝／祝福／希望：

### 2. 應用文：書信

題材例：
- 給老師的一封信
- 給偶像的一封信
- 給爸爸的一封信

教學方法：
1. 認識書信與信封基本格式。
2. 先確定收信人與寫信目的。
3. 蒐集要說的事情與感情。
4. 完成正文後檢查格式與內容是否完整。

題材例：
- 科學博物館
- 我的學校
- 圖書館

教學重點：
- 說清楚事物的外形、內部構造、擺設、功能與特色。
- 先分類觀察資訊，再安排介紹順序。

- 外觀：

## 三下主線

### 1. 記敘文：狀物

題材例：
- 我的教室
- 我的小天地
- 我家的客廳

教學方法：
1. 實際觀察或看照片。
2. 分類記錄外觀、構造、位置、功能與特別之處。
3. 決定方位式、總分式、並列式或因果式結構。
4. 加入人在其中的活動與感受，避免只寫物件清單。

### 2. 應用文：條據／便條

題材類型：
- 請假條
- 留言條
- 邀約條
- 答謝條
- 收據
- 借據

教學方法：
情境判斷 → 選擇文類 → 格式辨識 → 範例閱讀 → 改錯 → 實作。

# 四年級

## 四上主線

### 1. 記敘文：敘事

題材例：
- 戶外教學
- 科博館參觀記
- 到超級市場

教學方法：
1. 找出事件主線：原因／開始 → 經過 → 高潮或最特別事件 → 結果。
2. 可採時間式、事件式或因果式。
3. 各段都要有事件發展，不只列出去了哪些地方。
4. 在重要事件後加入當時感受與想法。

- 結果：
- 我的感受：

### 2. 應用文：日記

教學重點：
- 認識日記基本格式。
- 從一天中選一件最值得寫的事。
- 避免流水帳，聚焦事件與感受。

- 日期／星期／天氣：
- 今天最值得寫的一件事：
- 發生什麼：

### 3. 說明文：事理／方法

題材例：
- 我的讀書方法
- 書桌的整理方式
- 掃地的方式

教學方法：
1. 先操作或回想流程。
2. 找出步驟並排序。
3. 補上注意事項與理由。
4. 從讀者角度檢查：照著文章做是否能完成。

## 四下主線

### 1. 記敘文：記景

題材例：
- 美麗的校園
- ○○公園
- ○○海邊

核心方法：
- 定點觀察：固定位置，讓視線依序移動。
- 移步換景：依行走路線安排景物。
- 常用順序：由上而下、由遠而近、前後左右、依移動路線。

學習單：

- 第一個景物：看見、聽見、顏色／形狀、感受

- 最後我對這個地方的感受：

### 2. 應用文：讀書報告

教學重點：
- 蒐集書籍基本資訊。
- 說明主要內容，不把全文重新抄述。
- 選擇印象最深的內容並寫出原因。
- 形成自己的理解與感受。

學習單：
- 書名：
- 作者：
- 主要內容：
- 印象最深的內容：
- 為什麼：
- 我學到／想到：
- 是否推薦及理由：

### 3. 說明文：規則與禮儀

題材例：
- 上下學的要求
- 用餐禮儀
- 電話禮儀

教學方法：
規則用途 → 具體步驟／要求 → 注意事項 → 為什麼要這樣做。

# 五年級

## 五上主線

### 1. 議論文：如何型

題材例：
- 如何保護環境
- 怎樣做個孝順的好孩子
- 如何做一個好學生

核心問題：怎麼做？

教學方法：
1. 找出核心問題。
2. 先說明為什麼重要。
3. 列出二至三個可實行的方法。
4. 每一個方法配合理由與例子。
5. 結尾回扣主張。

學習單：
- 我的主張：

- 方法一／原因／例子：

- 結論：

### 2. 童話：擬人類

題材例：
- 勇敢的小熊
- 貪心的咪咪
- 大樹傳奇

教學重點：
- 把動物、植物或物品賦予人的思想、語言與行動。
- 先設計角色個性，再安排問題與事件。
- 仍需完整故事結構。

故事鷹架：
背景 → 引發事件 → 主角想法／目標 → 嘗試解決 → 障礙 → 結果 → 結局。

- 遇到什麼障礙：
- 最後怎麼解決：
- 結局：
- 故事想表達：

### 3. 童詩：寫人類

題材例：
- 老師生氣的時候
- 有趣的○○○
- 可愛的○○○

教學重點：
- 選人物最突出的特徵。
- 練習譬喻、重複與節奏。
- 用具體形象表達感受，而非平均介紹所有人物資料。

學習單：

### 1. 議論文：為何型

題材例：
- 讀書的重要
- 守信的重要
- 合作的重要

核心問題：為什麼重要？

教學方法：
1. 先寫清楚自己的看法。
2. 找出二至三個理由。
3. 每個理由搭配生活例子或經驗。
4. 檢查所有理由是否支持同一主張。
5. 結尾回扣主旨。

- 我的觀點：
- 理由一＋例子：

題材例：
- 慢吞吞國傳奇
- 神奇的小精靈
- 不可思議的事

教學方法：
1. 從「如果……會怎樣？」開始。
2. 設定與現實不同但前後一致的世界規則。
3. 推想這個假定造成的改變。
4. 讓主角因這個規則遇到問題並解決。

學習單：

- 世界變成：
- 三條世界規則：

- 結局：

## 範文分析

1. 文章題目與文體。
2. 每段大綱。
3. 心情／感受語句。
4. 成語。
5. 譬喻、擬人與其他修辭。
6. 最值得仿寫的段落。
7. 準備遷移到自己文章的結構與內容。

## 仿寫三層

1. 句型仿寫：保留語法結構，替換內容。
2. 段落結構仿寫：保留主題→事件→感受等層次。
3. 全文結構仿寫：保留組織方式，但人物、事件、內容與觀點改為自己的。

仿寫不是只換名詞。

## 完整寫作與修正

建議先口述再筆述：
1. 先說給同學或教師聽。
2. 檢查資訊是否完整、順序是否合理。
3. 再寫成文字。
4. 用詞彙與修辭補強，而非先堆成語。
5. 完稿後檢查是否回應題目、段落是否單一、例子是否具體、感受是否有原因、開頭與結尾是否回扣主題。

# 來源差異與限制

1. 本知識庫的主要課程主線來自維護者提供的「作文寫作課程設計」資料；另以兩份寫作研習資料補充文體、審題、結構、大綱、層次、教學流程與範文解析。
2. 部分來源的五、六年級題材安排不完全一致，本知識庫保留主線與補充模組，不將不同來源硬併成不存在的單一版本。
3. 部分來源形成於民國97～101年前後，仍使用「能力指標／課程標準」等舊課綱語彙。本知識庫沒有把舊標籤改寫成現行課綱。
4. 正式教案若需核心素養、學習表現、學習內容，必須另查現行 Canonical 課綱知識庫。
5. 本頁中的學習單是依來源方法重新整理成可重複使用的模板，不代表原始教材逐字存在相同表格。
6. 若來源沒有完全相同題目，可遷移相同文體與寫作結構，但不得假稱該題目原本就在來源教材中。

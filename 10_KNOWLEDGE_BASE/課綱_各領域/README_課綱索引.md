## 載入原則
1. 先依教案的主要領域選擇對應 Markdown。
2. 再依學習階段、核心素養、學習表現、學習內容等需求檢索相關段落。
3. 跨領域教案才載入第二個以上領域。
4. 需要總綱核心素養、議題融入或跨域對齊時，再載入 `00_總綱.md`。
5. 科技領域依教育階段區分國小參考資料與國中／高中正式科技領域課綱。

# 20_TEMPLATES

eduHarness Cloud 的可重用模板區。

## 用途

保存可跨任務使用的教案、文件、評量、教材或其他工作模板。Skill 若需要既有 Template，應依 ENV 與 Brain Index／Registry 的規則定位，不應自行猜測 installation 路徑。

## Installation 規則

此目錄是標準 runtime 結構的一部分。安裝或修復流程應確保 Google Drive 中存在 `20_TEMPLATES`，即使目前沒有模板。

本 `README.md` 用於讓 GitHub Canonical Distribution 保留此目錄；Git 本身不追蹤空資料夾。

## 邊界

只應將可分享、portable 的模板納入 Canonical Distribution。教師個人資料、學生個資與 installation-specific locator 不應回推 GitHub。

# 30_EXPERIENCE

eduHarness Cloud 的可重用經驗資料區。

## 用途

保存已確認且值得跨任務重用的教學、工作流程或系統操作經驗，供後續任務參考與索引。

## Installation 規則

此目錄是標準 runtime 結構的一部分。安裝或修復流程應確保 Google Drive 中存在 `30_EXPERIENCE`，即使目前尚未累積任何 Experience。

本 `README.md` 用於讓 GitHub Canonical Distribution 保留此目錄；Git 本身不追蹤空資料夾。

## 邊界

一次性的 working state 不應自動持久化為 Experience。只有可跨任務重用且已確認的內容才適合保存；不得包含學生個資、秘密或 installation-specific locator。

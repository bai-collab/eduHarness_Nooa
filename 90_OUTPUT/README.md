# 90_OUTPUT

eduHarness Cloud 的正式輸出區。

## 用途

保存任務完成後、已確認需要交付或保留的輸出成果。它與 `50_WORKSPACE` 的草稿及中間產物分離。

## Installation 規則

此目錄是標準 runtime 結構的一部分。安裝或修復流程應確保 Google Drive 中存在 `90_OUTPUT`，即使目前沒有輸出檔案。

本 `README.md` 用於讓 GitHub Canonical Distribution 保留此目錄；Git 本身不追蹤空資料夾。

## 邊界

輸出是否保存、公開或正式送件仍須遵守對應 Skill 與 Human Gate。教師 installation 的實際成果不應因 Canonical Distribution 同步而自動上傳 GitHub。

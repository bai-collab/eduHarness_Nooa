# 99_ARCHIVE

eduHarness Cloud 的封存區。

## 用途

保存已退出主要工作流程、目前不需主動使用，但仍有保留價值的舊資料或歷史內容。

## Installation 規則

此目錄是標準 runtime 結構的一部分。安裝或修復流程應確保 Google Drive 中存在 `99_ARCHIVE`，即使目前沒有封存內容。

本 `README.md` 用於讓 GitHub Canonical Distribution 保留此目錄；Git 本身不追蹤空資料夾。

## 邊界

Archive 不代表可刪除。刪除資料屬高影響操作，仍須遵守 Human Gate；封存內容也不得因 Distribution 同步而自動公開或回推 GitHub。
